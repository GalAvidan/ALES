# Project Overview

**Project:** 30-Second Brand Spot — Product Reveal

## Purpose

A punchy, upbeat 30-second animation that reveals the product for the first time in a paid social
campaign. Goal: stop the scroll, communicate one core benefit, leave the viewer wanting more.

## Core Message

> One sentence the viewer must remember: "[Product name] makes [pain point] disappear."

## Deliverables

- Final render: 1920×1080 @ 60fps, H.264, ≤ 50 MB
- Social cut: 1080×1080 @ 30fps (square format for Instagram)
- Stills: 3 key-frame exports at 300 dpi for print/banner use

## Constraints

- Runtime: exactly 30 seconds (±0.5s)
- No dialogue or voiceover — music and motion only
- Product must appear no later than second 12
- Brand logo must appear in last 4 seconds, centered, minimum 1 second hold
